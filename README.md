📚 Mi biblioteca personal

Aplicación web para organizar una biblioteca personal, consultar información de los libros y gestionar el estado de lectura y los favoritos.

Este proyecto forma parte de mi aprendizaje en desarrollo web y está construido con HTML, CSS y JavaScript.

✨ Funcionalidades implementadas

Catálogo de libros generado dinámicamente mediante JavaScript.

Tarjetas con portada, título, autor, género y valoración.

Marcado de libros como leídos y favoritos.

Estadísticas que se actualizan automáticamente según el estado de los libros.

Persistencia de los estados mediante localStorage, para conservar los cambios al recargar la página.

Diseño responsive adaptado a diferentes tamaños de pantalla.

🛠️ Tecnologías

HTML5: estructura y contenido.

CSS3: diseño, Flexbox, CSS Grid y adaptación responsive.

JavaScript: gestión de datos, generación de tarjetas, eventos y actualización de estadísticas.

JSON: serialización y recuperación de los datos de los libros mediante JSON.stringify() y JSON.parse().

localStorage: almacenamiento de los datos en el navegador.

🚀 Cómo ejecutar el proyecto

Clona este repositorio o descarga sus archivos.

Abre la carpeta del proyecto en Visual Studio Code.

Ejecuta index.html con la extensión Live Server.

Interactúa con los botones de lectura y favoritos para comprobar cómo cambian las estadísticas.

No se necesita un proceso de compilación ni instalar dependencias para ejecutar la versión actual.
